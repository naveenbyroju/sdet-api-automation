# SDET API Automation Framework

A Python-based API automation testing framework built using Pytest and Requests.

## Features

- GET API automation
- POST API automation
- PUT API automation
- DELETE API automation
- Reusable API client
- Pytest fixtures
- Basic logging
- Response status code validation
- Response body validation

## Tech Stack

- Python
- Pytest
- Requests
- Git
- GitHub
